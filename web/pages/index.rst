Sphinx-RTL : A showcase
=============================

Introduction
--------------------

This webpage does show, on a real project what could be done with sphinx-rtl as an extension !
The original source of the project was an RiscV 32 bits core, available publicly here : https://github.com/lheywang/RV32/tree/main.

Even if this core does not properly work (I'm close, but this project was abandoned, so it'll never be working), it contains
interesting RTL concepts that made it a nice example !

And, even better : I've originally written it in VHDL, and latter migrated it to SystemVerilog, so we'll explore both today.
Pick your preference, and go !
